Fountain, explained

One prompt, one machine.

Fountain is a conversational API to a computer. You send a prompt to an HTTP endpoint. A machine wakes with your repos, packages and credentials already in place, a coding agent works on it, and the answer comes back. The machine then goes to sleep with its disk intact, and the next prompt picks up the same files.

This is a scripted simulation, not a live run. Timings, log lines and the price are illustrative. The request shapes, endpoint names and rules come from the Fountain docs and source.

    Where does the secret go?

    You put a GitHub token in a vault so the agent can open a pull request. A skeptical engineer should ask where that token ends up. It depends on the account, so pick one.
